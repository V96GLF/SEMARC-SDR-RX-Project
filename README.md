# SEMARC-SDR-RX-Project

This is a SEMARC Project to create a simple SDR receiver based on a Pi Pico.

The original idea comes from "101 Things", Pi-Pico RX Breadboard Version which is documented here:

https://101-things.readthedocs.io/en/latest/breadboard_radio.html
